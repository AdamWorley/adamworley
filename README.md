# Adam Worley

Software engineer at [@netwealth](https://github.com/netwealth), based in England.

I spend most of my time in **C# / .NET**, keep my machines reproducible with **Nix & NixOS**, and reach for **Go**, **Rust** or **TypeScript** when a side project calls for it. I like infrastructure as code, tidy developer tooling, and doing Advent of Code in a language I don't know yet.

I also write at [**Wordley Blog**](https://blog.adamworley.com) — mostly about communication, working well, and the human side of engineering.
